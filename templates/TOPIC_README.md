## Current status

- Proposal or coordinating issue:
- Activity status: proposed / active / paused / concluded
- Evidence status: untested hypothesis / partial result / conditional result / reproduced result / independently reviewed result
- Latest evidence or check date:
- Source transcription / sign records:
- Literal output (retain gaps and awkward wording):
- Interpretation / translation (state whether partial):
- Missing public evidence:

Explain what has actually been established and what remains unresolved. An activity status is not a verdict on the claim. Name the exact claim, date, scope and review record behind any “reproduced” or “reviewed” description. Separate author-reported checks from blind independent reconstruction. An open draft PR is proposed work, not a published edition.

## Start here

Link the source records, transcription, hypotheses, research log, code and results that actually exist. Give a short reading path from evidence to literal output and interpretation. Say which essential items are missing or cannot be distributed.

## Reproduce the checks

Give one source → sign → key/model → output example that can be checked without programming, if available. Link a minimal procedure with exact inputs, versions, dependencies and expected outputs. State which packages each command and CI workflow includes; a passing replay does not establish historical truth. State source-access or environment limits. Summarize what another person has independently checked and what they have not. If reproduction is not yet possible, say what is needed; do not invent a command.

## Research scope and limitations

Summarize the literal result, interpretation, and confidence separately. Identify uncertain signs, assumptions, editorial repairs, translations, unresolved values, and alternative explanations. Include important negative results. Do not describe coverage as accuracy or a finite search as excluding every possibility. Preserve dated results and post-test corrections as distinct records.

## Contribute

List a few small, concrete open questions with links to issues. Contributors can coordinate in an issue, fork the public repository, and submit a PR without organization membership. Constructive challenges and independent replications are welcome.

## Sources and rights

List the institution or collection, catalogue identifier, stable link, and exact page or image. State what has been inspected and what remains unavailable. Credit previous editions, readings, keys, transcriptions, datasets, and code. Clearly identify any application or correction of a known key.

Credit contributors by their chosen public attribution and describe their contributions. Record relevant AI tools and how their output was checked. Preserve each source's rights and permissions; identify which licence or terms apply to each class of material. Do not imply that the repository's licence covers third-party scans. If rights are unclear, link the authorized source and state the gap.
